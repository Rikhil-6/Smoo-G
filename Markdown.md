## Main Agentic Planning Outline

Smoo-G is starting as a small agent simulator for topic review, debate, and synthesis.

Core direction:

- Launch 2-3 mini agents by default, then make the count tweakable.
- Give each agent a distinct perspective such as business, ethical, technical, customer, legal, or creative.
- Run a topic through multiple rounds and produce a transcript plus synthesis.
- Keep the first UI in static HTML so it works cleanly in GitHub Pages.
- Use GitHub branches or worktrees for larger experiments and push regularly.

Integration targets:

- **Daytona** for isolated execution environments.
- **VideoDB** for video-derived scenario material.
- **Kimi** for live model-backed agent responses.
- **Sense-Nova** and **BrightData** as future research or data-source layers when the workflow needs them.
